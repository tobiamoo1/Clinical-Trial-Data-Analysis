# Clinical-Trial-Data-Analysis
The aim of this project is to analyse clinical trial data to uncover insights that can help determine the efficacy and safety of new medication.

To achieve this, analysis of data from a phase III clinical trial for a new Type 2 diabetes medication was conducted using Python. The data was imported, cleaned and analysed using statistical methods. Then visualisations were created to communicate the findings. 

The dataset used is the “Diabetes Medication Clinical Trial Dataset”, which contains information about patient demographics, treatment groups, blood glucose levels, HbA1c levels, adverse events, and other relevant clinical measurements over the 12-month trial period.
